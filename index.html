How to Make This Website Live • ویب سائٹ لائیو کرنے کا طریقہ

Step 1: Save File as index.html • فائل کو index.html کے نام سے محفوظ کریں

Download or copy ae-news-portal.html and save it as index.html in a folder.

اس فائل کو ڈاؤن لوڈ یا کاپی کریں اور ایک فولڈر میں index.html کے نام سے محفوظ کر لیں۔

Step 2: Free Instant Hosting (Netlify Drop / Vercel / GitHub Pages)

Go to app.netlify.com/drop and drag-and-drop your folder containing index.html — you get a live URL in seconds.

Netlify Drop، Vercel یا GitHub Pages پر فولڈر اپ لوڈ کریں، چند سیکنڈز میں لائیو لنک مل جائے گا۔

Step 3: Custom Domain & cPanel / Hosting Upload

If you already bought a domain (like aenewspaper.com), log in to your hosting File Manager → public_html and upload index.html.

اگر آپ کے پاس ڈومین اور ہوسٹنگ ہے تو کنٹرول پینل کے public_html فولڈر میں index.html اپ لوڈ کر دیں۔

Step 4: Live Verification • لائیو چیک لسٹ

Open your live URL on mobile & desktop and check breaking news ticker, PKT live clock, Facebook feed, and Gulberg Lahore map.

لائیو لنک کو موبائل اور کمپیوٹر پر کھول کر ٹکر، لائیو گھڑی، فیس بک فیڈ اور گلبرگ آفس کا نقشہ چیک کریں۔
